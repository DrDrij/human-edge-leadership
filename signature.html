Outlook

  1. Click Copy signature above.
  2. Outlook → Settings → Mail → Compose and reply (or File → Options → Mail → Signatures on Windows).
  3. Create a new signature, click into the editing box and paste (Cmd+V / Ctrl+V).
  4. Set it as the default for new messages and replies, then save.

Gmail

  1. Click Copy signature above.
  2. Gmail → Settings (gear) → See all settings → General → Signature.
  3. Create new, paste into the box, scroll down and save changes.

Apple Mail

  1. Click Copy signature above.
  2. Mail → Settings → Signatures → choose the account and click +.
  3. Paste into the signature area. Untick “Always match my default message font”.

The Copy HTML code button copies the raw markup instead, for clients or tools that accept pasted HTML source.
